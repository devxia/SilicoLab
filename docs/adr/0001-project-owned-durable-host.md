# 项目目录持有科研状态，单一 Node 宿主持久化对话

依照首版规格 #1 和任务 #4，采用 pi-durable 作为唯一智能体持久化内核，pi-ai 负责模型接入，保留现有 Python 科学工具与本机 HTTP 应用入口。每个项目的 SQLite 位于用户选定目录的 `.silicolab/` 中；应用级索引只保存项目身份、名称与定位信息，不能替代项目的唯一科研状态。

通过 Node 子进程的私有 JSONL 协议连接 Python 工作台模块；界面与测试使用相同的工作台外部操作，不直接编辑 SQLite。Python 对规范化项目路径持有 POSIX advisory lease，子进程继承 lease 描述符，防止父进程意外结束时仍存活的 Node 与第二宿主重叠写入；进程及文件系统异常下不承诺零丢失。

打开或列出项目不会启动内核调度器、提交模型或触发科学计算。多个对话保存为内核 conversation 与应用文档；草稿是可修改的编辑状态，科研任务和输入版本将以独立身份扩展，不能把聊天内容或界面卡片当作任务完成。

模型凭据不属于项目，不通过读取其他 agent 认证便利接入。现有手动 ProteinFactory／D2P 工作台保持独立入口；新工作台尚未接入的模型、任务、文件或产物显示为空，不用模拟记录伪装实际能力。运行时精确锁定已验证发布包 1.4.0，不能假设同版本源码快照中的新接口存在。

布局采用已接受的 A 对话主体与 C 可展开图标导航；分析区首次打开时记录导航偏好并收窄，手动展开不因切换分析标签重置，关闭分析区恢复记录偏好，布局变化不重建对话或清空草稿。

Node/Python 随包分发、原生后台生命周期、多任务逐项恢复和模型兼容均有独立验收任务，本切片不提前宣称通过。
