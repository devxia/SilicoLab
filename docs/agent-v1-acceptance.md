## 交付与未扩大范围

- 单一主循环为pi-durable1.4.0；没有嵌套Pi coding-agent SDK/RPC。科学操作通过受管Python监督器执行，数据来源和不确定状态分开。
- 升级/备份明确管理`.silicolab`状态，不归档Keychain或用户原始目录；执行契约不匹配阻止继续，保留检视与导出。没有任意存储故障零丢失或端到端exactly-once承诺。
- 产品包为Intel x86_64、macOS15.7.7实测，声明最低13.0但不把13.x写成实测；ad-hoc、未Developer ID/未公证，Gatekeeper未获认可声明。
- 没有真实GPU/集群、通用蛋白设计、载体接头扩展、团队服务、自动预算、自动恢复、默认取消远端或其他agent认证扫描。
- 源码发布与本地生成DMG/ZIP不是GitHub Release发布或部署授权。research、私人输入、本机路径、运行数据库、凭据、截图和分发二进制不提交。
