# 密码子优化

## 输入与计算

支持粘贴单条蛋白或多条 FASTA、拖入文本，以及 XLSX/CSV/TSV。单条最多 10,000 字符，一批最多 200 条，导入文件最多 5 MB。表格支持选择工作表、表头行、起始行、名称列和序列列；空行跳过，错误行必须明确选择才会忽略。

工作簿最多 20 个工作表，每页最多 2,000 行、100 列，全工作簿最多 100,000 个单元格，解压总量最多 40 MB。公式只读取缓存值，不执行公式、宏或外部链接；旧版 XLS 和 Excel 临时锁文件不支持。名称以文本导出，避免被解释为 Excel 公式。

已有末尾 `*` 原样保留。缺少时提示补充或保持原序列，不猜测起始 M，也不改变内部非法终止符。表格预览在本机完成，不提交序列。

默认引擎是 ProteinFactory 远端。它目前无需 Cookie、Token 或 API key，但属于网站内部接口，服务行为可能改变。选择本地实验时仅支持 D2P 默认体系；失败、无解和重试不会回退上传。

两种引擎共用串行队列。远端请求间隔 0.5 秒、超时 120 秒；401/403/429 暂停后续远端任务，本地仍可继续。停止会停止后续提交，已发送的远端请求无法撤回。重启后未完成项标记为中断，由用户决定是否重试。

## 本地实验引擎

无约束时按固定首选密码子表编码；有约束时对同义密码子搜索，依次最小化修改的密码子数与碱基数。避免位点同时检查正向和反向互补，包括跨密码子和重叠位点。

支持最多 128 个位点，单个位点最长 256 bp，总长最多 8192 bp，默认 500 万次候选扩展。预算耗尽与确定无解分别报错。结果再通过 DNA 字符、长度、翻译和位点校验。

原研究的独立人工测试中，无约束 6/6 条与远端一致；有约束 8/8 条合法，其中 3/8 条与远端完全相同。测试集较小，不能据此保证任意输入复现远端，也没有蛋白表达实验。

运行实现位于 `backend/src/silicolab/features/codon/local.py`，密码子表位于相邻 `resources/`，不依赖本地研究目录。记录包含版本、代码/表哈希、约束策略与计算来源；引擎指纹变化后旧任务不能混用重试结果，可复制成新任务。

## 结果与历史

显示 DNA、分段密码子对照、GC 与校验，不展示未经验证的表达提升分数或 CAI。复制和导出使用完整序列。

Excel 仅包含“基因合成”工作表，三列依次为“序号、合成名、核酸序列”，字体、列宽、对齐和边框沿用空白模板，无注释、无额外工作表；仅导出通过校验的结果。FASTA 支持单条/批量；ZIP 保留参数、原始响应和历次尝试。

历史支持单条/批量删除，最多 1,000 项。排队、运行、正在停止时禁止删除，后端同样校验；批量有冲突时整批拒绝。数据库原始记录和摘要同事务删除，删除当前结果不清除未提交草稿。已导出文件、预设和远端记录不随本地删除而删除。

## 本机存储

仅监听本机地址，拒绝外部 Host/Origin，无遥测或云同步。数据库不是加密数据库，删除也不等于磁盘安全擦除。浏览器草稿使用 localStorage，当前任务使用 sessionStorage；原生应用数据和导出路径见项目 README。
