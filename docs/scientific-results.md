# 科研结果检视与可追溯导出

对应 #8。右侧“结果”区只从已保存任务/执行尝试读取真实科学结果，不触发新的模型或计算。

## 结果区

- 科学状态与模型状态分开：全部通过、部分完成、计算失败按真实逐条记录判定；失败条目显示错误和“无结果”，不会被列为通过。
- 序列表保持输入顺序，列为合成名、实际 DNA 长度、GC、状态；列宽稳定、数字对齐，较小窗口可横向滚动。
- 选定条目可查看完整 DNA、逐位氨基酸/密码子对照、独立校验和来源。DNA/蛋白/指纹用等宽文本和受限滚动容器；显示空间受限不截断复制或下载内容。
- “校验与来源”关联固定输入哈希、原始/实际蛋白、终止符/避免位点、引擎版本、代码/映射指纹、task/attempt/tool/call身份及原始工具响应。
- “复制完整 DNA”使用完整保存字符串，支持原生剪贴板或浏览器剪贴板；失败明确提示使用 FASTA，不伪装复制成功。
- 多个执行结果可按任务/尝试切换；结果标签具有 ARIA 面板关联、选中标签单一 Tab 焦点、左右方向键与 Home/End 操作。切换侧栏、结果标签或刷新只重连状态，不 submit、resume 或执行工具。
- 旧保存结果若没有报告级 attempt 字段，使用同一历史执行中已存在的 id/toolTaskId/callId 展示来源，不改写历史或重算补齐。终止符字段未保存时从实际保存蛋白判断存在性；没有保存的原始响应明确标为历史字段缺失，而非伪造。

## 产物

所有文件均在项目的任务/尝试输出目录保存，记录路径、长度和 SHA-256；HTTP 下载只接受已声明产物名，读出前核验完整性。文件名不是任意路径权限。

| 文件 | 内容 |
|---|---|
| `synthesis.xlsx` | 只导出通过校验条目，保持原始相对顺序；复用已有模板，单“基因合成”工作表、“序号、合成名、核酸序列”三列，无注释/额外记录页 |
| `synthesis.fasta` | 所有成功条目的完整 DNA，保持顺序；没有失败条目的伪造 DNA |
| `sequence-NNN.fasta` | 对应原始输入索引的单条成功 DNA；失败索引不存在相应产物 |
| `record.json` | 实际科学状态、逐条成功/失败、原始响应、参数、输入哈希、引擎信息及当前执行尝试 |
| `records.zip` | 完整记录包，包含下列内部文件；即使全失败，也保留失败记录与来源 |

ZIP 中包括：`record.json`（成功/失败均保留、原始工具响应）、`task.json`（稳定任务/对话/请求身份、目标、参数、输入版本与创建时间）、`input-version.json`（固定来源、长度/哈希/版本）、`inputs/NNN.fasta`（原始固定字节），有成功项时还包含与单独下载**同一字节**的合成 Excel 和批量 FASTA。

记录包对应一次具体尝试，不把模型答复当作工具结果，也不事后覆盖旧尝试。任务/工具重试和恢复会保留既有记录，由相应执行控制任务进一步验收。校验通过不是表达效果保证。
